# Bazzite_Custom_Build-Nvidia
# Bazzite Custom Build

This repository contains my personal custom build configuration based on:

`bazzite-deck-nvidia:stable`

The goal is to keep Bazzite as close to the official stable image as possible while automatically adding a few useful desktop applications and gaming-related extensions.

## Included Applications

* Discord
* Google Chrome
* VLC Media Player
* Decky Loader

## Included Decky Plugins

* SteamGridDB
* HLTB for Deck
* ProtonDB Badges

## Installation Method

The desktop applications are installed via Flatpak.

Decky Loader is installed using Bazzite's supported `ujust` setup method.

The Decky plugins are installed automatically from the current Decky plugin store during the first setup.

## Purpose of This Build

This build is mainly intended for personal use and provides a ready-to-use Bazzite installation with my preferred applications and gaming extensions already prepared.

The underlying Bazzite system remains as close as possible to the official stable image.
